# ``RobinCore``

Share application composition, configuration, diagnostics, metadata, and output contracts across Robin packages.

## Overview

RobinCore contains transport- and renderer-neutral values used throughout the framework. Applications normally encounter these types through higher-level Robin packages.

## Topics

### Application composition

- ``ApplicationMode``
- ``ApplicationRoute``
- ``ApplicationTheme``
- ``Metadata``

### Configuration and diagnostics

- ``ConfigurationValues``
- ``Environment``

- ``Diagnostic``

### Generated output

- ``OutputLayout``
